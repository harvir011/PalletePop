## ✨ Overview

**PalettePop** is a lightweight and interactive web application that makes discovering beautiful color combinations effortless.

Whether you're designing a website, creating a brand identity, or experimenting with colors, PalettePop helps you generate, explore, and organize color palettes in seconds.

Built using Vanilla JavaScript, HTML5, and CSS3, the application combines a clean user interface with practical functionality and persistent local storage.

## 🚀 Features

| Feature | Description |
|---|---|
| 🎲 Random Generation | Generate unique five-color palettes instantly. |
| 🔒 Color Locking | Lock your favorite colors while regenerating the remaining palette. |
| 📋 HEX Copying | Copy individual HEX color codes with one click. |
| ❤️ Favorites | Save your favorite color combinations. |
| 💾 Persistent Storage | Retain saved palettes even after refreshing the browser. |
| 🌙 Dark Mode | Switch between light and dark themes. |
| ⌨️ Keyboard Shortcut | Press the Spacebar to generate a new palette. |
| 📱 Responsive UI | Enjoy the application across desktop and mobile screens. |

## 🛠️ Tech Stack

**Frontend**
- HTML5 — Semantic page structure.
- CSS3 — Styling, transitions, layouts, and responsive design.
- Vanilla JavaScript — Dynamic rendering and application logic.

**Browser APIs**
- DOM API — Interactive user interface.
- Clipboard API — Copy HEX color codes.
- LocalStorage API — Persistent favorites and theme preferences.

## ⚙️ Getting Started

Follow these steps to run PalettePop locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/PalettePop.git
```

### 2. Navigate to the project directory

```bash
cd PalettePop
```

### 3. Open the project

Open the folder in VS Code.

You can launch `index.html` using the Live Server extension.

Alternatively, open the HTML file directly in your browser. Note that clipboard functionality requires localhost or HTTPS in supported browsers.
